# email-service
Generic email service
To use this service first we need to set required parameters in Run configuration of project.
Parameters which required to be set,
1) MAIL_SENDER :- Email address from which you want to send an email. 
2) MAIL_HOST :- Domain from which email will send. (Ex. smtp.gmail.com)
3) MAIL_PORT :- Port of the domain. (Ex. 587)
4) MAIL_USERNAME :- Username which display to recipient.
5) MAIL_PASSWORD :- Password of your email address.
